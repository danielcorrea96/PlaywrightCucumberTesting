# Playwright Product Test Plan Skill

This SKILL file defines allowed tools and guidance for producing product requirement documents, test plans, and Playwright test scaffolding for web applications.

When invoked, the skill should:

- Inspect the user's prompt and any attached workspace files (features, fixtures, pages).
- Produce Markdown docs (requirements and test plan) and TypeScript test scaffolding compatible with Playwright.
- Optionally run `npm`/`pnpm` test commands when the user explicitly permits execution.
